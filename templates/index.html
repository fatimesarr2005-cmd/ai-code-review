Exemple d’entrée

import torch

diff_hunk

 import torch

Exemple pratique : le commentaire attendu peut signaler que l’import torch.nn n’est peut-être pas nécessaire.

Instructions d’utilisation

  1. Colle la version précédente dans old_file.
  2. Colle le changement exact dans diff_hunk.
  3. Clique sur Analyser.
  4. Lis le commentaire généré puis vérifie-le manuellement avant usage réel.
